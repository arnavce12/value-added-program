Features
💬
AI Chat
Powered by Mistral Pixtral with full session memory. Understands context across the entire conversation.
📎
File Understanding
Upload JPG, PNG, or PDFs up to 10MB. Pixtral reads and reasons about images and scanned documents natively.
🌐
Multilingual
Respond in 11 languages including Hindi, Marathi, Tamil, Telugu, Bengali, and more — switchable mid-conversation.
🔊
Text-to-Speech
Edge TTS voices for English and regional Indian languages. Zero extra API calls — runs via a local endpoint.
🧠
Session Memory
SQLite stores full chat history per browser tab. Auto-created on first run — no setup needed.
🎛️
Response Styles
Concise, Detailed, Formal, or Simple (ELI5). Injected into the system prompt — ~10 token overhead only.
Setup
01
Clone & Install
Clone the repo and install all dependencies.
git clone <your-repo-url>
cd chatbot
npm install
02
Configure Environment
Copy the example env file and add your Mistral API key. Get one at console.mistral.ai.
cp .env.example .env
MISTRAL_API_KEY=your_key_here
PORT=3000
03
Start the Server
The SQLite database and uploads folder are created automatically on first run.
node server.js
04
Open in Browser
Navigate to http://localhost:3000 — the chatbot is ready.

API Endpoints
Method Endpoint Description
POST /api/chat Send message, receive AI reply with session history
POST /api/upload Upload file (JPG / PNG / PDF, max 10MB)
POST /api/tts Convert text to speech audio (Edge TTS)
DELETE /api/session/:id Clear session data and delete uploaded files
