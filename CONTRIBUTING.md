# Contributing to Value Added Program

Thanks for your interest in contributing! Please follow the steps below.

---

## Ground Rules

- Do **not** edit or modify another person's project folder.
- Only contribute to a project if it is open for contributions (check the project's README).
- Keep your changes clean and well-commented.
- One pull request per fix or feature — don't bundle unrelated changes.

---

## How to Contribute

### Step 1 — Fork the Repository
Click the **Fork** button on the top-right of this repo page.  
This creates your own copy of the repo under your GitHub account.

### Step 2 — Clone Your Fork
```bash
git clone https://github.com/<your-username>/value-added-program.git
cd value-added-program
```

### Step 3 — Create a New Branch
Never work directly on `main`. Create a branch for your change:
```bash
git checkout -b your-branch-name
```
Example: `git checkout -b fix-project1-login`

### Step 4 — Make Your Changes
- Work only inside the relevant project folder.
- Test your changes before committing.

### Step 5 — Commit and Push
```bash
git add .
git commit -m "Brief description of your change"
git push origin your-branch-name
```

### Step 6 — Open a Pull Request
1. Go to your forked repo on GitHub.
2. Click **Compare & pull request**.
3. Add a clear title and description of what you changed and why.
4. Submit the pull request.

---

## Pull Request Review
- All pull requests are reviewed by **@arnavce12** before merging.
- You may be asked to make changes before approval.
- Do not merge your own pull request.

---

## Questions?
Open an [Issue](../../issues) on the repo and describe your question or suggestion.
